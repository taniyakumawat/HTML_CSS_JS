# Controllers (business logic per resource)

Created from **Phase 3 onwards**. One controller per resource, e.g.:

- `auth.controller.js` - login, register, forgot password (Phase 3)
- `student.controller.js` - CRUD students (Phase 4)
- `teacher.controller.js` - CRUD teachers (Phase 4)
- `attendance.controller.js` - mark/edit/fetch attendance (Phase 5)
- `report.controller.js` - analytics + exports (Phase 7)
